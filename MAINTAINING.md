# Maintaining the GitHub profile

GitHub renders README.md on the itsNikolay profile because this public repository matches the account name.

## Add a project

Copy a project section and insert it above the PROJECTS marker in README.md. Give it a short benefit-led introduction, a source link, an optional demo or installation link, and three to five relevant technology tags. Use an image with meaningful alt text when it helps explain the project. Images can live in assets/ or use public raw GitHub URLs. Put the most important project first; move older projects below the marker as the collection grows.

Keep project descriptions and button labels in English. Use real screenshots and working links. Avoid counters and externally generated activity widgets so the page stays fast and stable.

The header is a self-contained SVG in assets/header.svg. Edit its text and palette there; no build or dependencies are required.
